# DevOps Internship - Task 1

## Automate Code Deployment Using GitHub Actions

### Objective
Create a CI/CD pipeline that automatically tests, builds, and pushes a Docker image whenever code is pushed to the `main` branch.

### Tools Used
- GitHub
- GitHub Actions
- Node.js
- Docker
- Docker Hub

### Workflow
1. Push code to GitHub.
2. GitHub Actions runs automatically.
3. The application is tested.
4. A Docker image is built.
5. The image is pushed to Docker Hub.

### Project Files
- `app.js`
- `app.test.js`
- `package.json`
- `Dockerfile`
- `.github/workflows/main.yml`

### Result
Successfully created a CI/CD pipeline using GitHub Actions.
